About
I built a SaaS AI Startup Orchestrator using React and Gemini 2.5 that runs a multi-agent system (CEO, CTO, CMO, CFO) with structured JSON outputs. It automatically generates complete startup plans including strategy, product, marketing, pricing, and growth with simulated tool integrations.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/2c201885-1c39-4aad-8712-b673697401b3

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
